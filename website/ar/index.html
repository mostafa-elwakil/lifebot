المميزات

كل ما تحتاجه للتركيز، في مكان واحد

بدل ما تفتح خمسة تطبيقات: مؤقت، مهام، مشاريع، مزامنة، وتحليلات — كلها في نافذة واحدة خفيفة.

⏱️

بومودورو عائم فوق كل شيء

مؤقت صغير يبقى أعلى الشاشة أثناء العمل في أي برنامج. فترات تركيز، بريك قصير، وبريك طويل تلقائي كل ٤ دورات — مع صوت وإشعار.

📁

مشاريع ونسبة إنجاز

اجمع المهام داخل مشاريع، واحسب التقدم تلقائيًا ٢/٥ · ٤٠٪. انقل مهمة موجودة لمشروع، أو أنشئ مشروعًا من نفس الحوار.

🧠

مدرب Hermes الذكي

خطة صباحية، حلول للأعذار («مش فاضي»، «مش عارف أبدأ»)، ومراجعة يومية. يعمل مع Gemini، وبدونه يقدّم وضعًا محليًا مفيدًا.

🔄

مزامنة ثنائية مع Joplin

مهامك تظهر فورًا في Projects/Lifebot/Tasks مع tags وموعد استحقاق، وتسحب مهام Joplin للبرنامج بضغطة — مع منع التكرار.

📅

مزامنة ثنائية الاتجاه في كل مكان

أضف المهمة أو عدّلها أو أتمّها أو احذفها مرة واحدة — يحدّث ركّز Google Tasks وJoplin وNotion في الخلفية بدون نسخ مكررة. أتمّ المهمة من أي خدمة فتُعلَّم مكتملة هنا أيضًا، ثم ينتقل الإتمام إلى البقية. وزر «اختبار الاتصال» يتحقق فعليًا من الصلاحيات.

📊

تحليلات حقيقية

دقائق التركيز خلال ٧ أيام، توزيع الوقت على التصنيفات، أيام الاستمرار (Streak)، وعدد المهام المنجزة — من بياناتك أنت.

🎨

فاتح وداكن، وأربعة تصاميم

ثيم Dark (Tokyo Night) وLight (Paper)، وألوان تمييز وحجم وشفافية وخلفية قابلة للتخصيص — والودجت يعدّل تباينه تلقائيًا.

⬆️

تحديث بضغطة واحدة

لا صفحات إصدارات ولا تنزيل يدوي: البرنامج ينزّل المثبّت الجديد مع نسبة تقدم، ثم يثبّته ويعيد التشغيل بنفسه.

💻

طرفية + API محلي

كل شيء متاح من سطر الأوامر (إضافة، إتمام، مشاريع، إحصاءات، مزامنة) وأيضًا HTTP API محلي تشغّله من الإعدادات → API ويمكنك حمايته بـ Token.

البداية

من التحميل للتركيز في ٣ خطوات

  1. ١

    حمّل وثبّت

    ملف واحد لويندوز ١٠/١١، بدون Python ولا إعدادات معقدة. بياناتك تُحفظ في %APPDATA%\Rakez\data ولا تتأثر بالتحديث.

  2. ٢

    اكتب مهامك ومشاريعك

  3. ٣

    اضغط تشغيل واشتغل

    الودجت يبقى فوق كل البرامج. عند انتهاء الجلسة يظهر إشعار، ويُسجَّل الوقت في تحليلاتك وتقويمك.

الأسئلة الشائعة

أسئلة يسألها الجميع

هل البرنامج مجاني فعلًا؟

نعم. لا حسابات ولا اشتراكات. تفعيل مدرب AI وGoogle اختياري ويستخدم مفاتيحك الخاصة، لذا لا توجد رسوم من ركّز.

هل تُرفع بياناتي لأي مكان؟

لا. كل شيء في قاعدة بيانات محلية على جهازك. المزامنة تحدث فقط لو فعّلت Joplin أو Google بنفسك، وحينها تذهب مباشرة للخدمة التي اخترتها.

لماذا يظهر «Unknown publisher» عند التثبيت؟

لأن المثبّت موقّع باسم Mostafa Elwakil بشهادة ذاتية التوقيع لا يثق بها SmartScreen افتراضيًا. تحقّق من تبويب Digital Signatures في خصائص الملف ثم اختر More info → Run anyway. إزالة التحذير للجميع تتطلب شهادة OV/EV مدفوعة.

هل يعمل بدون إنترنت؟

نعم، البومودورو والمهام والمشاريع والتحليلات والتصاميم تعمل بالكامل أوفلاين. الإنترنت مطلوب فقط لمدرب Gemini والمزامنة والتحديثات.

كيف أضبط Google؟

أنشئ OAuth Client من نوع Desktop app في Google Cloud Console، فعّل Calendar وTasks، وأضف بريدك في Test users، ثم الصق Client ID وSecret في الإعدادات → API واضغط Authorize ثم Test connection.

كيف أضبط Notion؟

أنشئ تكاملًا من notion.so/my-integrations، وشارك قاعدة البيانات معه (⋯ ← Connections)، ثم الصق السر في الإعدادات → API ومعرّف قاعدة البيانات في الإعدادات → التكاملات → Notion. اضغط Test ثم Sync now.

ماذا يحدث لبياناتي عند التحديث؟

لا شيء. البيانات في %APPDATA%\Rakez\data منفصلة عن ملفات البرنامج، لذا تبقى كما هي بعد كل تحديث.

هل يوجد إصدار لينكس أو ماك؟

لينكس: يمكن البناء من المصدر عبر packaging/build_linux.sh. ماك غير مدعوم رسميًا حتى الآن — التطبيق مبني بـ PyQt6 لذا يعمل نظريًا لكن بدون مثبّت جاهز.
